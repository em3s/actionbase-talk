# Docs — Toolkit

발표를 계속 만들어 나가기 위한 **재사용 도구함**. 발표별 결정·메모는 `talks/talkN/` 또는 `.claude/talkN/`에 둠.

| 파일 | 내용 |
|---|---|
| [`overview.md`](overview.md) | 시리즈 구성 · 우산 모델 · 세션 간 경계 원칙 |
| [`design.md`](design.md) | 포맷 선택 · 컬러 팔레트 · 타이포 · mermaid · 빌드·배포 · 단축키 |
| [`references/`](references/) | 외부 자료 보존본 (verbatim) |

## 발표별 자료 위치

- `talks/talkN/notes.md` — 발표 메타·톤·thesis
- `talks/talkN/narrative.md` — 발표 서사 구조
- `talks/talkN/design.md` — 발표별 슬라이드 레이아웃·구성 결정
- `.claude/talkN/` — script-draft, script-final 등 작업 메모
